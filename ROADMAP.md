# Roadmap

Where Full Send goes next. Ideas move into a release once they have a drill design that keeps the standard-library, fast-judge rules. Suggestions and pull requests are welcome.

## Shipped in v1.0

- Nine levels, twenty-eight drills, from linear algebra to a cited-answer capstone
- `fullsend.py`: init, next, check, hint, status, card, reset, doctor, build, verify, new
- Fork-safe design: learner files are generated locally and never shipped upstream
- PocketRAG capstone with a golden evaluation set

## Shipped in v1.1

- `fullsend.py`: sync, watch, `status --json` and `card --badge`
- A judge that kills a runaway drill instead of waiting for it, plus tests for the runner itself
- A pass-rate gate for the capstone evaluation, used by CI
- `AGENTS.md` for AI coding assistants, a dev container and an "Open in Codespaces" badge

## Next drills

| Level | Idea | Teaches |
| --- | --- | --- |
| L2 | Adam from scratch | Why adaptive learning rates train faster than plain SGD |
| L4 | Skip-gram with negative sampling | Learned embeddings, compared against 4.3's counting vectors |
| L5 | Multi-head attention and a tiny character transformer | Splitting heads, residuals and layer norm |
| L6 | Vector index with cosine search | Brute force first, then a simple inverted-file speed-up |
| L7 | Planner and executor agents | Splitting a task, checking each step's result |
| L7 | Tracing for the agent loop | Recording every step, tool call and cost so a run can be replayed |
| L7 | A minimal tool protocol | A small request and response format for tools, in the spirit of MCP, over plain functions |
| L8 | Token-bucket rate limiter | Smoothing bursts of API calls without dropping requests |
| L8 | Prompt injection filter | Treating retrieved text as data, never as instructions |
| L8 | Cost and latency budget | Counting tokens and time per call, and failing a run that overspends |

## Tooling

- A static web view of the board and briefs, generated by `build`
- Optional adapters that let the capstone call a real language model when a key is present, while the judge stays offline
- Translations of the briefs, contributed per level

## Non-goals

- Heavy frameworks in the core path. They belong in optional extras.
- Drills that need a GPU, network access or a paid API to pass.
