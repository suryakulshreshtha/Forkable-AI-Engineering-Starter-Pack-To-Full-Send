# The kit

Finished versions of things earlier drills ask you to build. Later drills import from here, so a bug in your level 2 autograd never haunts you in level 7. Read a kit module after you clear the matching drill, not before.

| Module | Unlocked by | Contents |
| --- | --- | --- |
| `kit.linalg` | 1.1 Dot, Matvec, Matmul | `dot`, `matvec`, `transpose`, `matmul`, `add`, `scale`, `norm` |
| `kit.autograd` | 2.1 Scalar Graph | `Value`, a scalar autodiff engine |
| `kit.nn` | 2.2 Neurons and Layers | `Neuron`, `Layer`, `MLP` |
| `kit.mathx` | 5.1 Softmax and Friends | `softmax`, `logsumexp`, `log_softmax`, `sigmoid` |
| `kit.retrieval` | 6.1 Chunker, 6.2 BM25 | `chunk_words`, `BM25` |
| `kit.tools` | 7.1 Tool Registry | `ToolRegistry` |
| `kit.text` | (helpers) | `words`, `content_words`, `sentences`, `STOPWORDS` |
| `kit.fakemodel` | (helpers) | `ScriptedModel`, a replayable stand-in for a language model |
